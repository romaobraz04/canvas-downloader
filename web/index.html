Connect to Canvas

Your token is sent only to the Canvas proxy and is never stored on the server.

How do I create a token?
  1. Open Canvas and go to Account → Settings.
  2. Find Approved Integrations and create a new access token.
  3. Give it a purpose, set an expiry date, then copy the token here.
